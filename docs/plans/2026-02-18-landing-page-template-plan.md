# Landing Page Template Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Create a reusable Astro template with React + shadcn/ui (Base UI) for building static landing pages served by nginx via Docker/Traefik.

**Architecture:** Astro generates static HTML at build time. React components from shadcn/ui (Base UI primitives) render to HTML server-side — zero JS shipped unless `client:*` directives are used. Landing sections are composable `.astro` components. Each landing is a clone of this template, built into a Docker image with nginx.

**Tech Stack:** Astro 5.x, React 19, shadcn/ui (Base UI), Tailwind CSS v4, Lucide React, pnpm, nginx, Traefik v3

```json
{
  "extends": "astro/tsconfigs/strict",
```

**Step 2: Create MobileNav.tsx**

Interactive React component using Sheet for mobile menu:

```tsx
import { Button } from "@/components/ui/button";
import {
  Sheet,
  SheetContent,
  SheetTrigger,
} from "@/components/ui/sheet";
import { Menu } from "lucide-react";

interface MobileNavProps {
  links: Array<{ label: string; href: string }>;
  cta: { label: string; href: string };
}

export default function MobileNav({ links, cta }: MobileNavProps) {
  return (
    <Sheet>
      <SheetTrigger asChild>
        <Button variant="ghost" size="icon">
          <Menu className="h-5 w-5" />
        </Button>
      </SheetTrigger>
      <SheetContent side="right" className="w-[300px]">
        <nav className="flex flex-col gap-4 mt-8">
          {links.map((link) => (
            <a
              key={link.href}
              href={link.href}
              className="text-lg font-medium text-muted-foreground hover:text-foreground transition-colors"
            >
              {link.label}
            </a>
          ))}
          <Button asChild className="mt-4">
            <a href={cta.href}>{cta.label}</a>
          </Button>
        </nav>
      </SheetContent>
    </Sheet>
  );
}
```

**Step 2: Create nginx.conf**

```nginx
worker_processes auto;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    sendfile on;
    tcp_nopush on;
    keepalive_timeout 65;

    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript image/svg+xml;

    server {
        listen 80;
        server_name _;
        root /usr/share/nginx/html;
        index index.html;

        # Cache static assets
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }

        # Security headers
        add_header X-Frame-Options "SAMEORIGIN" always;
        add_header X-Content-Type-Options "nosniff" always;
        add_header Referrer-Policy "strict-origin-when-cross-origin" always;

        # Static pages — no SPA fallback
        location / {
            try_files $uri $uri/ =404;
        }

        # Custom error page
```
